# بوت تداول الذهب (محاكاة آمنة)

هذا مشروع Python لبوت يتعامل مع بيانات `XAUUSD` (الذهب مقابل الدولار)، مع اختبار CSV وطبقة اختيارية لـ MetaTrader 5. التنفيذ على MT5 لا يحدث إلا عند تمرير `--execute` صراحةً؛ الوضع الافتراضي يفحص ويسجل فقط.

> **تنبيه:** هذا مثال تعليمي، وليس نصيحة استثمارية أو ضماناً للأرباح. الاختبار التاريخي لا يتنبأ بالنتائج المستقبلية.

## ما الذي يفعله؟

- يقرأ شموع OHLCV من ملف CSV.
- يدخل شراءً حين يكون EMA السريع أعلى البطيء وRSI ضمن نطاق زخم محدد.
- يحدد وقف الخسارة وجني الربح من ATR، ويحسب حجم الصفقة وفق نسبة مخاطرة ثابتة من الرصيد.
- يدير صفقة واحدة فقط، ويغلقها عند وقف الخسارة/الهدف أو عند انعكاس الإشارة.
- ينتج ملخصاً للرصيد والصفقات وملفاً اختيارياً بسجل التنفيذ.

## التثبيت والتشغيل

يتطلب Python 3.10 أو أحدث، ولا يحتاج إلى حزم خارجية:

```bash
python -m gold_bot --help
python -m gold_bot backtest --csv /path/to/xauusd.csv --trades-out trades.csv
python -m gold_bot mt5                       # فحص حساب MT5 وتسجيل القرارات فقط
python -m gold_bot mt5 --symbols XAUUSDm --execute  # حساب تجريبي أولاً
```

### صيغة البيانات

يجب أن يتضمن CSV الأعمدة التالية (الأسماء بحروف صغيرة):

```text
timestamp,open,high,low,close,volume
2026-01-01T00:00:00Z,2620.0,2622.0,2618.0,2621.0,1200
```

يمكن إغفال `volume`. الشموع يجب أن تكون مرتبة زمنياً، ويجب أن تكون قيم OHLC موجبة ومنطقية.

## حدود السلامة

- يلزم تثبيت حزمة `MetaTrader5` وتشغيل تطبيق MT5 وتسجيل الدخول إليه على نفس الجهاز قبل أمر `mt5`.
- يكتشف تلقائياً الأسماء التي تتضمن `XAU` أو `GOLD`، لذلك يدعم صيغ الوسيط مثل `XAUUSD` و`XAUUSDm` و`GOLD.pro`؛ لا يمكن ضمان توفر رمز لا يقدمه وسيطك.
- لا تُرسل أوامر إلا مع `--execute`. استخدم حساباً تجريبياً أولاً.
- تشمل الحماية: مخاطرة افتراضية 0.5% للصفقة (بحد أقصى 1%)، مع رفض الصفقة إن كان أصغر حجم لوت لدى الوسيط يتجاوز تلك المخاطرة، وحد خسارة يومي افتراضي 2%، وحد للصفقات المفتوحة واليومية، ومنع صفقات/أوامر الرمز المكررة، وحد للسبريد، وسجل JSONL كامل للقرارات.
- يتحرك وقف الخسارة للصفقات الطويلة الرابحة فقط وفق ATR، ولا يُسمح له مطلقاً بالرجوع للخلف أو بالانخفاض عن سعر الدخول.
